# YouTube Shorts – formulations

Four 30-second vertical Shorts (1080×1920, MP4) in `videos/`, made by `make_shorts.py`.
The videos are silent: add a trending sound in the YouTube app when you upload.

Change text or add a new formulation by editing the `SHORTS` list in `make_shorts.py`
(set `WEBSITE` to your real domain), then run `python3 make_shorts.py`.
